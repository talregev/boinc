BOINC client — Chrome runtime harness

Loads the wasm client, runs it on the browser event loop (cooperative main loop), and once initialized, drives GUI RPC live via boinc_handle_gui_rpc (no socket). RPC replies + errors are streamed to the server (/report → runs.jsonl).
